# 首都圏 天気・運行情報

埼玉県川口市・東京都台東区の天気予報と、首都圏のJR・東京メトロの運行情報を確認するWebサイトです。

## 機能

- 2地域の1時間ごと（現在から12時間）、今日・明日、今日から3日後までの天気予報
- ライト／ダークテーマの切替（選択をブラウザに保存）
- 天気と運行情報をまとめて更新する操作
- 遅延・事故・運転見合わせ・直通運転中止がある路線だけを表示する運行情報エリア

## データソース

- 天気：Open-Meteo Forecast API（非商用・無料枠で利用）
- 運行情報：公共交通オープンデータセンター（ODPT）API

ODPTのアクセストークンが未設定の間、運行情報は「準備中」として扱います。実在しない運行障害情報は表示しません。

## 開発

Windowsでは、ディレクトリ名に `&` を含むため、通常のnpmスクリプト実行時に問題が生じる場合があります。その場合は、プロジェクトのフォルダ名を英数字に変更したうえで、以下を実行してください。

```bash
npm ci
npm run dev
```

## Cloudflareの設定

ODPTの承認後、Cloudflare Workerのシークレットとして `ODPT_API_TOKEN` を設定します。トークンの値をGitHubへコミットしたり、チャットへ送ったりしないでください。
